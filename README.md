# AirScroll

AirScroll is an AI-powered gesture and voice-controlled desktop automation system developed using Python.

## Features

- Hand gesture recognition
- Air mouse control
- Air scrolling
- Voice commands
- Browser automation
- QR code support
- Real-time webcam processing
- GUI-based desktop application

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Tkinter
- PyAutoGUI
- SpeechRecognition
- Selenium
- Flask

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AirScroll.git
```

### Move into Project Folder

```bash
cd AirScroll
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Virtual Environment

#### Windows

```bash
.\.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python update.py
```

## Build Executable

```bash
pyinstaller --onedir --windowed --icon=airscroll_icon.ico update.py
```
